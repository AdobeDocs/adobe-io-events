# GenStudio Events

Adobe GenStudio for Performance Marketing emits events when approved Experiences are created, have their metadata updated, or are deleted. Subscribe to these events through Adobe I/O Events to react in near real time, instead of polling the [GenStudio API](https://developer.adobe.com/genstudio-api/).

Events are published under the **GenStudio Events** provider, using the [CloudEvents v1.0](https://cloudevents.io/) envelope.

For the full event catalog, payload shapes, delivery characteristics, and step-by-step subscription instructions, see [Experience Events](https://developer.adobe.com/genstudio-api/guides/experience-events/) in the GenStudio API documentation.
